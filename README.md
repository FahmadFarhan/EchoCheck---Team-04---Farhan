# ⚖️ SentinelVoice Forensics

> **AI-Assisted Audio Evidence Analysis Workstation for Legal Cases & Investigations**

SentinelVoice Forensics is a preliminary audio-evidence analysis platform engineered for forensic examiners, litigation lawyers, legal-support teams, investigators, and corporate compliance officers.

It combines two foundational voice intelligence engines from **DetectifAI**:
1. **DetectifAI Aletheia**: Foundation model for AI-generated synthetic voice and voice-clone detection.
2. **DetectifAI Eidos**: Foundation model for biometric speaker enrollment and verification.

Alongside these neural models, the workstation provides **deterministic audio container & signal integrity inspection** and structured forensic case records.

## ⚖️ Legal Forensics Principles & Limitations

- **Preliminary Decision Support Only**: This platform is designed for preliminary evidence screening, case intake triage, and organizing forensic case files. It does **not** provide a definitive judicial verdict or determination of legal admissibility.
- **Not CFSL / NFSU Certified**: Automated AI analysis does not replace certified forensic examiners or accredited government forensic laboratories such as the **Central Forensic Science Laboratory (CFSL)** or the **National Forensic Sciences University (NFSU)**.
- **Synthetic Detection vs. Speaker Identity**:
  - **Aletheia (Deepfake Detection)** determines whether speech acoustic features were synthetically generated by an AI model. A "real" verdict does not confirm who is speaking or that the recording is untampered.
  - **Eidos (Speaker Verification)** determines whether a voice matches an enrolled reference voiceprint. An acoustic match does not prove physical presence or intent, nor does it rule out an AI clone of that individual.
  - These two analyses are tracked separately and are never merged into an unsupported aggregate score.
- **Evidence Integrity (SHA-256)**: Every submitted recording is hashed upon upload to support chain-of-custody documentation.

## 🎯 Core Features & Workflows

### 1. Evidence Assessment Station
- Input legal matter reference, dispute category, and alleged speaker.
- Optionally select an enrolled reference speaker from the Eidos voiceprint library.
- Upload disputed audio recordings (`.wav`, `.mp3`, `.m4a`, `.ogg`, `.flac`).
- Automatically triggers:
  1. DetectifAI Deepfake Integrity Analysis (`POST /v1/deepfake/detect`)
  2. DetectifAI Eidos Speaker Verification (`POST /v1/speakers/verify`)
  3. Audio Container & Signal Integrity Inspection
- Generates an explainable assessment report with forensic guidance and next steps.

### 2. Eidos Speaker Enrollment Station
- Register reference voiceprints under a unique Speaker ID (`^[A-Za-z0-9_.:-]{1,64}$`).
- Attach optional display names and provenance notes (how and where the reference exemplar was recorded).
- Upload reference recordings meeting DetectifAI's documented criteria: **15–60 seconds duration with at least 10 seconds of clear speech**.
- Add up to 5 reference samples per speaker to improve model robustness.
- Review enrolled speakers directory with the option to remove voiceprints (`DELETE /v1/speakers/{speaker_id}`).

### 3. Defensible Audio-Integrity Inspection
Deterministic, technical signal measurements implemented in [`audio_integrity.py`](file:///Users/dheemanthgirish/Desktop/SENTINEL.AI/audio_integrity.py):
- **Container Format & Codec**: Validates headers (WAV RIFF, MP3 ID3, FLAC, M4A).
- **Sampling Rate & Channel Layout**: Identifies telephony rates (8/16 kHz) vs studio rates (44.1/48 kHz) and Mono/Stereo channels.
- **Peak & RMS Level (dBFS)**: Signal loudness and dynamic range / crest factor.
- **Clipping / Saturation Ratio**: Detects the percentage of samples at or near full-scale (`>= 0.995`), indicating microphone overload or digital limiting.
- **Inactivity / Silence Ratio**: Measures intervals below `-45 dBFS`.
- *Limitation*: Acoustical signal properties are not proof of editing or tampering. Compression, background noise, or pauses can create artifacts.

### 4. Forensic Case Registry & Reporting
- Audit-ready SQLite database capturing case references, hashes, API request IDs, and examiner findings.
- One-click export of the **Preliminary Audio Evidence Analysis Report** (`.txt`).
- CSV export for litigation file management.

## 🔑 DetectifAI API Scopes & Configuration

Ensure your API key in `.env` has the following scopes enabled in your [DetectifAI Dashboard](https://platform.detectif.ai):

| Scope | Description |
| :--- | :--- |
| `deepfake:detect` | Required for synthetic voice / deepfake detection |
| `speakers:enroll` | Required for enrolling reference speaker voiceprints |
| `speakers:verify` | Required for verifying recordings against enrolled speakers |
| `speakers:read` | Required to list enrolled speakers in the directory |
| `speakers:delete` | Required to delete enrolled voiceprints |

Configure in `.env`:
```ini
DETECTIF_API_KEY=your_detectif_api_key_here
DETECTIF_API_TIMEOUT=30
```

## 🚀 Execution Instructions

### 1. Activate Environment & Run App
```bash
cd /Users/dheemanthgirish/Desktop/SENTINEL.AI
source .venv/bin/activate
streamlit run app.py
```
Open **[http://localhost:8501](http://localhost:8501)** in your browser.

### 2. How to Enroll a Speaker
1. Navigate to **Eidos Speaker Enrollment** in the sidebar.
2. Enter a unique Speaker ID (e.g. `SPK-ACCUSED-01`) and optional display name.
3. Upload an 18-second reference audio file (e.g. `samples/sample_speaker_enrollment_reference.wav`).
4. Click **"Enroll Speaker with Eidos"**.

### 3. How to Verify a Disputed Recording
1. Navigate to **Evidence Assessment** in the sidebar.
2. Enter your Case Reference (e.g. `CRIM-2026-88192`).
3. Under **Reference Speaker for Eidos Verification**, select the speaker enrolled above.
4. Upload the disputed recording (e.g. `samples/sample_disputed_call.wav`).
5. Click **"Run Forensic Audio Analysis"**.
6. Review the synthetic voice verdict, Eidos speaker match decision & similarity, and audio integrity inspection.
